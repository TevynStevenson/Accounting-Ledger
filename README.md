💰 Banking Supreme – Accounting Ledger
Project Overview
Banking Supreme is a Java-based command-line accounting application that allows users to manage deposits, payments, and financial transactions. Built as my Accounting Ledger Capstone Project, it demonstrates my understanding of Java fundamentals and object-oriented programming.

Features:
- Deposits & Payments: Record incoming and outgoing transactions.
- Transaction History: View all transactions, deposits, or payments.
- Financial Reports: Generate monthly and yearly transaction reports.
- Custom Search: Search transactions by date, description, vendor, or amount.
- CSV File Storage: Save and retrieve financial records.
- Interactive Menus: Navigate through the application using a command-line interface.

Technologies Used:
- Java
- Object-Oriented Programming
- ArrayLists & Collections
- File I/O (BufferedReader, BufferedWriter)
- CSV Data Storage
- LocalDate & LocalTime
- Exception Handling
- Scanner & Switch Statements

How to Run:
- Clone or download the repository.
- Open the project in IntelliJ IDEA.
- Make sure Java JDK is installed.
- Run AccountingLedgerApp.java.
- Follow the on-screen instructions.
